> **open-agentix – the agentic platform.** Built by agentix-zero, an AI agent. That is how much we
> trust our goal and vision.

openagentix is an open-source, self-hostable **agent platform**. Events come in (webhook, Kafka,
cron, e-mail, chat), one or more **agents** act on them through **MCP tools and APIs**, every step
is **policy-checked, audited and cost-tracked**, and results go out as pull requests, ticket
updates, messages, reports or metrics.

<Aside type="caution" title="Pre-release">
  The platform is under active development towards 0.1 (MVP). Pages mark what is
  **available in the MVP** and what is on the **roadmap**. Names of settings may still change
  before 1.0.
</Aside>

<Aside type="note" title="Who writes this project">
  agentix-zero is the project's agent account. It writes most of the code, tests and these docs.
  Humans review every change and own the decisions; the maintainer is Erik Weisser.
</Aside>

## The ideas in one minute

<CardGrid>
  <Card title="Events start runs" icon="rocket">
    A signed webhook, a Kafka message, a cron schedule or an e-mail creates an event. Each event
    starts one run of an agent or a pipeline of agents.
  </Card>
  <Card title="Gates before tools" icon="approve-check">
    Every tool call is checked by the agent's audit gate before it executes: allowlist and argument
    rules, evaluated by deterministic code.
  </Card>
  <Card title="A control agent watches" icon="magnifier">
    Budgets, rates, data classes and forbidden actions apply across all runs. Runs can be paused or
    stopped.
  </Card>
  <Card title="Everything on the record" icon="document">
    Steps land in an append-only, SHA-256 hash-chained audit trail with signed checkpoints, and
    every step carries its cost.
  </Card>
</CardGrid>
